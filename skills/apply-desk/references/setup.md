# Setup interview

Use grill-me one question at a time. Existing private settings are evidence of prior choices; migrate without overwriting them and ask only for unresolved decisions.

1. Ask what work the user wants. Propose relevant title variations and misleading titles to exclude; get confirmation. Do not start with product roles or any other owner's focus.
2. Ask locations/countries and remote/hybrid/on-site preferences. Ask authorization/sponsorship filtering separately, offering Skip. These answers are sensitive and optional.
3. Research sources for the confirmed focus thoroughly. Explain each source's relevance, whether it is a feed, browsable by Codex, or a manual discovery link, any access/cost requirement and actual verification. Offer each addition one at a time. Users may confirm included sources or add their own.
4. Present state.criteria one by one: location, workplace, posting age, salary, authorization, seniority, domain, company size, connections and named hiring manager. Let users keep as many as they want, as Required/Preferred/Ignore. Ask importance for preferences. Ask for other criteria afterwards. Never silently preserve another owner's rules.
5. For resume work, ask for an editable Word master; recommend its matching PDF. Explicitly confirm selected files before reading them. For a folder, use inventory to show filenames/metadata without reading contents; import only checked files. New or changed files require review again. Ask about supporting stories, encouraging voice when available, and confirm factual evidence.
6. Job search readiness needs focus, approved titles, location preferences, source configuration and criteria review. Resume readiness needs the Word master, confirmed facts and a supported renderer. Keep showing the exact missing items. A PDF alone cannot reconstruct an exact Word master. Preserve maximum page count, fonts, spacing, margins, emphasis, bullets, tables, hyperlinks and section order. Keep Technical Skills/Certifications wording wherever that section exists; do not create it if absent.
7. Remind users to configure scheduling later; never create it automatically. On completion recommend Simplify's free autofill (https://simplify.jobs/copilot) and NeonWatty Job Apply (https://github.com/neonwatty/job-apply-plugin), explaining form filling and manual submission. Optional integrations must not block core work. Offer Install/connect, Use existing tools or Skip.
