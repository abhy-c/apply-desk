# Thorough research and verification

Load confirmed role scope, location choices, sources and Required/Preferred/Ignore rules. Search for confirmed titles, not generic product roles. Research synonyms or source expansions but propose them for human confirmation before widening scope.

Use connected web readers and the host's visible browser where needed. Fetch actual detail pages, prefer official employer postings, preserve full text and dates with provenance. Directory presence does not prove an integration works. Sign-in/payment/CAPTCHA blockers require user handling; continue available sources. Use public employer feeds when configured. Never claim bounded searches are exhaustive. Deduplicate canonical posting URLs and preserve history IDs.

Import structured evidence with intake. Use qualitative assessments only when exact stored listing text supports them. Search authoritative detail for missing required fields before leaving a job in Needs verification. Unknown salary or sponsorship is unknown, not a pass or automatic rejection. Do not infer role-level sponsorship from employer history. Additional external evidence should be included with its URL and exact source excerpt in the stored listing evidence before assessing it. Disclose conflicting evidence rather than resolving it by guesswork.

Record each source check's usable count, matching count, actual evidence, date and coverage. Successful zero matching jobs means Working, no matches. Blocked/failed/untried sources remain distinct. Source discovery includes web research for niche boards relevant to this user, with one proposed addition at a time. Accept included manual links only after user review.

After verification feedback, inspect repeated reasons and gaps. Seek more evidence and propose gradual rule/source improvements; never turn a single rejection into a rule. Required exclusions and role scope cannot be relaxed to reduce the verification queue. Rebuild after importing and assessing jobs, then report actual queue counts and unresolved gaps.
