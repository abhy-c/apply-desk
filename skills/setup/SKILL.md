Read the package README before installation work. Ask whether the user already has an Apply Desk workspace; preserve it. Choose a folder outside the installed plugin cache. Locate a Python 3.11+ runtime and create the workspace's private environment; do not require another AI API key or alter global Python packages. Explain missing software and required permissions; let the user complete installer/license and operating-system dialogs.

Verify dashboard startup and show its local address. Help the user retrieve the private unlock code without putting it in logs, support reports or shared messages. Start a new chat if the installed skill is not visible. Use the main Apply Desk skill and its bundled grill-me setup interview for personal preferences. Do not read resumes or profile stores until the user selects them and consents.

Check search and resume readiness separately. Run the safe doctor report for dependency problems. Resume rendering requires Word on macOS; do not mark another renderer verified. Portal connections and Job Apply are optional: explain the portal preflight workflow, human sign-in and final manual submission. Never require setting up every portal before job search works. Remind the user to set up scheduling later after a successful manual search.
